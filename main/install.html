Platform Guides

Choose your platform, run the commands, and enter your API key once.

Download the batch script, run it, and enter your API key. The key is saved to C:\makeit\data\api.json.

curl -L https://hacker1514.github.io/make/scripts/win_set_up.bat -o win_set_up.bat && win_set_up

After installation, restart your terminal and run:

makeit

Download the shell script, make it executable, and run it. The key is saved to ~/.makeit/api.json.

curl -L https://hacker1514.github.io/make/scripts/linux_set_up.sh -o linux_set_up.sh && chmod +x linux_set_up.sh && ./linux_set_up.sh

After installation, restart your terminal and run:

makeit

Storage

Where Is My Key Stored?

Inside the Make It install directory, in a simple JSON file. Never inside your project folder.

📁 Location

On Linux/macOS/WSL: ~/.makeit/api.json. On Windows: C:\makeit\data\api.json.

📄 Format

{
  "server_url": "https://xxx.trycloudflare.com"
}

🔒 Security

Make It reads the key from this file automatically. It's never exposed in terminal history or logs.

🔄 Reset

To change your key, simply delete the api.json file and re-run the setup script.
