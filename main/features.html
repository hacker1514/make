Features

Everything Make It Can Do

A comprehensive set of AI-powered tools built into your terminal.

AI Coding

Write, refactor, and debug code in any language using natural language. Make It understands context and generates production-ready code on the fly.

File Editing

Make precise edits across multiple files with a single instruction. Insert, delete, or replace code blocks intelligently without breaking your project.

Project Generator

Generate full project scaffolds from a single prompt. Get a complete project structure with dependencies, configuration, and boilerplate code ready to run.

Command Execution

Let Make It run terminal commands safely with approval. From installing packages to running builds, it handles the shell so you don't have to switch context.

Memory

Remembers your project context across sessions. Make It keeps track of your file structure, recent changes, and preferences so you never repeat yourself.

Rich Terminal

A beautiful interactive terminal experience with syntax highlighting, color-coded output, and streaming responses. Works in any modern terminal emulator.

Cross Platform

Windows, Linux, macOS, WSL, and Termux — Make It runs everywhere you code. The same experience across all platforms with platform-specific optimizations.

KShell & Ollama

Runs on local or remote Ollama backend via KShell Cloudflare tunnel connection.

Fast Responses

Stream responses at blazing speed with no waiting. See the AI generate code character by character in real time, just like a pair programmer.

Open Source

Free, MIT-licensed, and community-driven. Full source code available on GitHub. Contributions, issues, and feature requests are always welcome.
