Architecture

Make It is built on a modular architecture that separates concerns into distinct layers:

🎛️ CLI Layer

Handles user input, command parsing, and terminal output. Built with argparse and rich for beautiful terminal rendering.

🧠 AI Layer

Orchestrates communication with the KShell & Ollama backend. Manages execution, context windows, and tools.

🔧 Tool System

Provides the AI with tools to interact with the file system, execute commands, and manage projects.

💾 Memory System

Persists project context, conversation history, and user preferences across sessions.

The AI communicates via KShell Client with the remote Ollama server. Responses are executed and returned in real-time to the terminal. The tool system is a set of Python functions that the AI can call to perform actions like reading files, writing files, and executing commands.

Configuration

Make It uses KShell Cloudflare server URL for configuration.

Variable Required Description
SERVER_URL Yes Cloudflare Tunnel URL generated from make_it.ipynb.
MAKEIT_MODEL No Ollama model to use (default: qwen2.5:3b)
MAKEIT_TEMP No Temperature for AI responses (default: 0.7)
MAKEIT_MAX_TOKENS No Maximum tokens per response (default: 4096)
MAKEIT_HOME No Custom config directory path (default: ~/.makeit)

Configuration is loaded from the AI_API_KEY environment variable at startup. Make It reads it automatically and never asks you to re-enter it.

Tool System

Make It provides the AI agent with a set of tools to interact with your system:

📄 read_file

Read the contents of a file. Used for understanding existing code before editing.

✏️ write_file

Create or overwrite a file with new content. Used for generating code.

🔍 search_files

Search for patterns across files using regex. Used for finding specific code.

📋 list_files

List files in a directory. Used for understanding project structure.

⚡ run_command

Execute a terminal command. Used for builds, tests, and installations.

🗑️ delete_file

Delete a file or empty directory. Used for cleanup.

📦 create_project

Scaffold an entire project structure from a template.

🧪 run_tests

Execute test suites and report results.

Each tool is implemented as a Python function with a clear schema that the AI understands. Tools can be extended or restricted based on user preferences.

Memory System

Make It remembers your project context across sessions using a persistent memory system:

💬 Conversation History

Stores recent exchanges between you and the AI, allowing coherent multi-turn conversations.

📁 Project Context

Remembers the project structure, recent files you've worked on, and important variables.

⚙️ User Preferences

Stores your preferred language, framework, and coding style for consistent outputs.

💾 Persistent Storage

Memory is stored in ~/.makeit/memory/ as JSON files, surviving terminal restarts.

The memory system is automatically managed. You can reset it with makeit --reset if needed.

LLM System

Make It integrates with KShell and Ollama to deliver AI responses:

⚡ KShell & Ollama

Uses Ollama engine for local and remote server responses. Tunneled via KShell Cloudflare connection.

🧠 Model Selection

Default model is Qwen2.5 3B (qwen2.5:3b). Customizable via MAKEIT_MODEL environment variable.

📝 System Prompt

A carefully crafted system prompt instructs the AI on how to use tools, understand projects, and generate code.

🔄 Remote Tunnel

Responses are executed and returned securely through KShell client connection.

The LLM system is designed to be modular. Future updates will add support for additional providers and local models.
