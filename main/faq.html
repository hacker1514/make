Frequently Asked Questions

Answers to the most common questions about Make It.

Installation

Getting Started

What is Make It?

Make It is a Terminal AI Coding Agent that lets you build, edit, and generate software projects directly from your terminal using natural language. It's powered by KShell and Ollama for fast AI responses.

How do I install Make It?

Download the appropriate setup script for your platform from the Download page, run it, and follow the prompts to enter your Cloudflare Server URL.

Does Make It work on my operating system?

Make It supports Windows, Linux, macOS, WSL, and Termux. Most major Linux distributions are supported including Ubuntu, Debian, Fedora, and Arch Linux.

What are the system requirements?

Make It is very lightweight. You need a modern operating system (Windows 10+, Linux, macOS 12+), an internet connection, and a KShell Cloudflare server URL. No Python installation is required — the binary is self-contained.

How do I update Make It?

Simply re-run the setup script for your platform. It will download the latest version and update the binary.

Connection

KShell & Server Configuration

How do I get a Cloudflare Server URL?

Follow the instructions at make_it.ipynb to launch your server and generate the Cloudflare tunnel URL.

Where is my connection configuration stored?

Make It stores your server URL in ~/.makeit/config.json (or %USERPROFILE%\.makeit\config.json on Windows).

How do I change my server URL?

Simply re-launch makeit and enter your new Cloudflare URL when prompted.

Is my connection safe?

Yes. The connection uses standard SSH authentication over Cloudflare secure tunnels.

Troubleshooting

Common Issues

Make It says "Cloudflare Server URL Required"

This means the server URL was not entered. Enter your Cloudflare URL generated from make_it.ipynb when prompted.

Make It is slow to respond

Check your internet connection and ensure your Ollama server process is active on the remote machine.

How do I completely uninstall Make It?

Delete the binary from the install location (e.g., /usr/local/bin/makeit or %USERPROFILE%\.makeit\makeit.exe) and remove the ~/.makeit directory.

Make It doesn't work in Termux

Make sure you have curl installed (pkg install curl) and that you're using Termux from F-Droid.

Still have questions?

Reach out to the developer or check the documentation for more details.
