The Story

Make It was born from a simple observation: developers spend too much time on repetitive tasks that an AI could handle. After building K-Drive (a virtual drive for GitHub repositories), I wanted to create something that would let developers describe what they want and have the AI build it.

The result is Make It — a terminal-based AI coding agent that combines the power of large language models with practical file system operations, command execution, and project scaffolding. It's designed to be the pair programmer you always wanted: fast, reliable, and always available.

Built with Python and powered by KShell & Ollama, Make It delivers responses efficiently. per second — making it one of the fastest AI coding agents available.

Why "Make It"?

The name reflects the core philosophy: tell the agent what you want to build, and it makes it. No complex configuration, no steep learning curve — just describe, and it's done.
