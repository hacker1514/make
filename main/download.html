Download

Get Make It

Choose your platform, download the setup script, and run it. The installer will prompt for your Cloudflare URL to connect.

Quick Start

One Command to Install

Just copy, paste, and run in your terminal. The installer handles everything.

After installation, simply run:

makeit

That's it. Make It reads your API key from ~/.makeit/api.json (or C:\makeit\data\api.json on Windows) automatically.

System Requirements

What You Need

Make It is lightweight and runs on almost any modern machine.

💻 Operating System

Windows 10/11, Linux, macOS 12+, WSL 2, or Termux.

⚡ KShell Tunnel

Cloudflare URL generated from make_it.ipynb.

📡 Internet

Required for connection to remote Ollama backend via KShell.

📦 curl

Required to download the installer. Pre-installed on most systems.

Installed? Just run makeit.

That's the only command you need. Make It connects via your KShell Cloudflare URL automatically.
